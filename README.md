Beat'em Up Prototype
A 2D Beat'em Up prototype developed in Unity and C# as part of the Udemy course "Jogo de Luta de Rua (Beat'em Up) na Unity"
The player can move around the stage and fight enemies using punches and kicks. 
The game features a combo counter system that increases when attacks successfully hit enemies within a combo timer.

Combat includes:
•	Punch attacks with a two-hit punch sequence.
•	Kick attacks.
•	Combo counter system.
•	Combo timer system.
•	Health recovery item drops based on probability when enemies are defeated.

The punch sequence is activated when the player successfully starts a combo and continues attacking enemies.

Controls:
Action	Key
Move	W, A, S, D
Punch	J
Kick	K
Technologies
•	Unity
•	C#
